# Макет сайта автосервиса, Мценск

Статический адаптивный макет для карточки «Автосервис», ул. Карла Маркса, 129. Его можно запускать локально, передавать на визуальную проверку и затем наполнять только подтверждёнными сведениями.

## Запуск

Откройте PowerShell в папке проекта и выполните `python -m http.server 8000`, затем перейдите на `http://localhost:8000`. Для чистого шаблона без данных выбранного предприятия откройте `http://localhost:8000/?profile=blank`.

## Профили и факты

- `data/business-profile.json` содержит только сведения, увиденные в карточке Яндекс Карт 3 ноября 2026 года.
- `data/blank-profile.json` не содержит данных конкретного предприятия.
- У каждого поля профиля есть `value`, `status`, `source`, `verified_at`. Неизвестное значение задаётся как `null` или пустой список, со статусом `unknown`.
- Рейтинг и счётчики описывают карточку Яндекса; они не обещают качество или исход ремонта. Индикатор посещаемости не подтверждает свободное время.
- Форма описания неисправности работает только в браузере и копирует текст. Она ничего не отправляет и не ставит диагноз.
- Номер телефона, график, услуги, прайс, совместимость автомобилей, порядок приёма, фото и ответы на вопросы не подтверждены и поэтому отображаются как уточняемые поля.

## Наполнение

Добавляйте факты в `data/business-profile.json` только после подтверждения от владельца или надёжного публичного источника. У каждого факта укажите источник и дату проверки. Список цен принимает объекты с полями `name`, `scope`, `unit`, `price`; список услуг принимает строки или объекты с полем `name`. Не используйте профиль Karl Marx 129 как профиль другого предприятия.

Цвета: тёмный `#10110f`, светлый фон и акцент `#dafa9c`. Семейство шрифта задано как Manrope с системными резервами; без доступа к Google Fonts браузер использует системный шрифт.
